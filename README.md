# etapp-site

Landing page + live demo for **[Etapp](https://github.com/tor2dbear/etapp)** —
deployed to `etapp.tor2dbear.com` (Cloudflare static-assets Worker, no build step).

- `/` — the landing page.
- `/demo` — a live Etapp board running on **fictional** data
  (`demo/data/build.mjs` generates `roadmap.json` + `roadmap.js`).

This is marketing + demo only. The product/tool is **tor2dbear/etapp**; a personal
instance runs at roadmap.tor2dbear.com.
